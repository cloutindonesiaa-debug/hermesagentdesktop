## Working yt-dlp Configuration

```bash
yt-dlp --cookies=/root/clipper-company/cookies_youtube_v2.txt \
  --user-agent "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/125.0.0.0 Safari/537.36" \
  --extractor-args "youtube:player_client=web" \
  -f "best[height<=720]/best" \
  -o "/root/clipper-company/downloads/%(title)s.%(ext)s" \
  "YOUTUBE_URL"
```

## Anti-Detection Tips

1. **Always use `--extractor-args "youtube:player_client=web"`** — this makes yt-dlp behave like a web browser
2. **User-Agent rotation** — use current Chrome UA (125+)
3. **Cookies** — keep them fresh, YouTube rotates cookies regularly
4. **Rate limiting** — don't batch more than 3-5 videos in quick succession
5. **Time delays** — add 5-10 second sleep between downloads
